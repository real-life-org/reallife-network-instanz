# Designsystem als Canvas

Die Arbeitsdateien der Design-Tafel. Jede `.dc.html` ist ein Artboard,
`canvas.json` legt sie an ihren Platz.

Geändert wird **hier**, nie in der zusammengesetzten Datei: die entsteht bei
jedem Lauf neu aus diesen Quellen.

`AppTokens.dc.html` wird aus `../branding/theme.json` erzeugt — wer die Tokens
ändert, erzeugt die Tafel neu, statt sie von Hand nachzuziehen. Sonst laufen
Bild und Wirklichkeit auseinander.
